# 🚀 TalentScope – AI Resume Intelligence Platform

TalentScope is an advanced AI-powered Resume Analyzer that transforms traditional resumes into actionable career insights. It uses modern AI to evaluate resumes, identify skill gaps, and generate personalized career roadmaps.

---

## 🌐 Live Demo

Example:(https://talent-scope-iota.vercel.app/)

---



## ✨ Features

### 🔍 AI Resume Analysis
- ATS (Applicant Tracking System) score generation
- Keyword optimization and role relevance check
- Resume formatting analysis

### 📊 Skill Gap Analysis
- Detects missing skills
- Suggests improvements based on job roles

### ✍️ Resume Optimization
- Improves weak bullet points
- Converts content into impactful, metric-based achievements

### 🧭 Career Roadmap
- Personalized learning paths
- Certification recommendations
- Step-by-step growth plan

### ⚡ Dual AI Modes
- Flash Mode (fast results)
- Pro Mode (deep analysis)

### 📄 PDF Report
- Download detailed analysis reports
- Clean and professional format

---

## 🛠️ Tech Stack

- Frontend: React 19 + TypeScript + Vite
- Styling: Tailwind CSS
- AI: Google Gemini API
- Animations: Framer Motion
- Icons: Lucide React
- PDF: jsPDF + PDF.js
